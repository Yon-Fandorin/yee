# Favorites

Favorites는 자주 여는 사이트를 Sidebar 상단에 아이콘으로 두는 독이다. Arc
Favorites에 가깝고, Arc Pinned Tabs가 아니다. Chromium pin이 백킹이다.

자세한 드래그는 [favorites-drag.md](./favorites-drag.md)를 본다.

## 모양

- 아이콘 독이다. 제목 행이 아니다.
- `FAVORITES` 라벨을 그리지 않는다.
- 독 배경은 비운다. 칸이 dimmed 채움을 가진다.
- 칸은 최소 32 DIP 정사각이 아니라, 행 안에서 폭을 나눠 가진다. 아이템이
  늘면 칸이 줄어든다.
- 높이는 파비콘 16 DIP와 상하 padding 8 DIP뿐이다. 높이 32 DIP. 폭과 높이를
  묶지 않는다.
- 한 행에 최대 4열, 전체 최대 12개.
- 모서리 8 DIP. 기본 채움 알파 110, hover 150, 활성 220. 스트로크 72 / 활성 140.
- 독 inset 6 DIP, 칸 간격 8 DIP.

고정 32px 열은 쓰지 않는다. 1px 흰 구분선만 있는 칸도 쓰지 않는다.

## 빈 상태

Favorite이 없을 때 평소에는 독과 빈 영역을 모두 숨겨 Tab 목록이 바로 위에서
시작한다. 실제 Tab 드래그가 시작되면 점선 카드가 Sidebar 폭을 채워, 탭을
올릴 수 있는 자리임을 보여 준다. 높이는 88 DIP다. 드래그가 끝나거나 취소되면
다시 숨기며, Favorite이 하나라도 있으면 이 빈 카드는 표시하지 않는다.

마지막 Favorite을 집으면 이 빈 카드를 바로 표시한다. 포인터가 Tab 영역으로
넘어가도 드래그가 끝날 때까지 높이와 공간을 유지해 Favorite으로 돌아갈 수
있게 한다. Tab에 놓기가 완료되면 높이 애니메이션 없이 즉시 제거하며, 한 칸
독을 중간에 복원하지 않는다.

현재 카피:

- 제목: `Favorites로 끌어다 놓기`
- 설명: `자주 쓰는 사이트와 앱을 가까이 둡니다`

## Split

스펙 의도는 Split Favorite이 칸 두 칸 폭을 쓰는 것이다. native가 독 전체
칸 폭을 두 배로 쓰는지는 구현을 잠그지 않고 제품으로 다시 확인한다.

## 용량

사용자가 새로 pin할 수 있는 개수는 12다. 이미 12개면 드롭과 컨텍스트 메뉴
pin을 막는다. 여러 탭을 한꺼번에 올리면 합이 12를 넘지 않아야 한다.
unpin은 항상 된다. 세션 복원과 API는 12를 넘긴 pin을 버릴 필요가 없다.

## 넣기와 빼기

- 컨텍스트 메뉴 / 키보드 pin
- Tab 목록에서 독으로 드래그
- 독에서 Tab 목록으로 드래그하면 unpin

실행할 URL을 만들지 않는다. 이미 열린 탭을 pin한다.

## 하지 않는 것

- Chromium pin과 별도 Favorite 모델
- Pins 슬롯을 Favorites 대신 쓰기 (예약, 켜기 전에 묻는다)
- 독 안에 그룹 헤더나 탭 제목 행을 섞기
