# Yee Agent 다음 작업

현재 판정과 수치는 [검증 결과](agent-browser-validation/results.md)를 따른다. 이
문서에는 아직 해결되지 않은 작업만 둔다.

## 다음 우선순위

1. 다음 구조 변경이 생기면 fresh composite 대신 각 조건을 중단 없는 단일 cohort로
   다시 수집한다. 현재 48/48 결론을 반복 실행만으로 갱신하지 않는다.
2. fresh seed11 S05에서 확인된 불필요한 탭 목록 조회와 분리된 wait/scroll 패턴이
   실제 사용에서 반복되는지 관찰한다. 새 증거 없이 특정 시나리오용 프롬프트를
   추가하지 않는다.

## 실행 원칙

- 변경 영향 사례를 먼저 재현하고 구조 변경을 묶은 뒤에만 고정 48개를 반복한다.
- Aside 조건이 그대로면 기존 baseline을 재사용한다. 조건이 달라진 자료만 보완한다.
- 실패 비용, 원본 응답과 Native receipt를 보존하며 실행기 문제로 제품 판정을
  바꾸지 않는다.
- 필수 gate가 통과하고 시간·토큰 목표가 확인되면 추가 후보 탐색을 멈춘다.
