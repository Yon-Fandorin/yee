# 웹페이지 영역의 테스트 기록

Browser Surface의 배치와 화면을 실제 macOS 앱에서 확인한 기록이다.
테스트별 결과와 캡처는 [상세 기록](results.md)에 보존한다.
현재 코드의 결과를 확인하려면 해당 테스트를 다시 실행해야 한다.

## 기록 안내

| 내용 | 확인할 곳 |
| --- | --- |
| 단일·분할 화면, 사이드바, 찾기 표시줄과 내부 패널 | [앱 화면 결과](results.md#실앱-결과) |
| 실패 재현과 애니메이션 분석용 자료 | [진단 자료](results.md#보존한-진단-자료) |
| C++·실제 UI 테스트 결과 | [자동 테스트 기록](results.md#당시-자동-회귀-검증) |
| 2026-09-05의 여러 전환이 겹치는 테스트 | [복합 전환 기록](results.md#복합-전환-회귀-체크포인트--2026-09-05) |
| 수행하지 못한 테스트와 확인 범위의 한계 | [남은 항목](results.md#당시-남은-검증-항목) |

## 결과를 읽을 때

단순히 보이는 위치와 실제 화면 픽셀 검증은 구분한다.
애니메이션이 끝난 캡처는 전환 중 모든 프레임의 정상 동작을 증명하지 않는다.
테스트 수는 여러 단계의 결과이므로 서로 합쳐 현재의 통과 수로 사용하지 않는다.

Windows·Linux 실행, 일부 기능 상태와 전체 화면 전환 중 화면은 확인이 남아 있다.
일부 캡처 도구의 제약과 간헐적 픽셀 실패도 상세 기록에 적었다.

현재 배치 기준은 [셸 명세](../browser-shell-spec.md), 구조는
[레이아웃 설계](../browser-surface-layout-design.md), 실행 방법은
[개발 도구](../../tools/dev/README.md)를 참고한다.
